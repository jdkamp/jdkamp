## Hi there 👋

I'm a software engineer with a background in control engineering, working mostly on safety-critical systems. In practice that means building embedded software: design, implementation, and the architecture and integration work around it. This work taught me to focus on the details.

What interests me is the intersection of **machine learning and control engineering**, mostly the part where they meet badly. Learned models are flexible where hand-derived ones aren't, but they arrive without the guarantees a control loop needs to be safe to run.

**Current project:** [mpc-framework](https://github.com/jdkamp/mpc-framework) — a C++17 framework for stochastic model predictive control with Gaussian-process-learned uncertainty, extended into a safe-exploration loop where a reinforcement learning agent trains behind an MPC-based safety filter.

**Working with:** C · C++ · Python
