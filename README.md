## Hi there 👋

I'm a software engineer with a background in control engineering, working mostly on safety-critical systems. In practice that means building embedded software: design, implementation, and the architecture and integration work around it. This work taught me to focus on the details.

I'm interested in bringing the mindset of safety-critical engineering to learning-based and numerical software: predictable performance, well-defined interfaces, and behavior you can test and reason about. Learned models are flexible where hand-derived ones aren't, but they arrive without the guarantees a real system relies on. I like to work on closing that gap from control loops to numerical kernels.

**Working with:** C · C++ · Python
